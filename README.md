# 🎓 Engenharia de Software - Centro Universitário Alves Faria (UNIALFA)

Este repositório centraliza as atividades práticas, laboratórios de código e resoluções de problemas desenvolvidos por mim durante a graduação em **Engenharia de Software** na UNIALFA.

O objetivo deste espaço é documentar minha evolução acadêmica e demonstrar a aplicação prática das teorias de engenharia, arquitetura de computadores, algoritmos e governança discutidas em sala de aula.
